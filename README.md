## Data and the script for reproducing the plots in the paper: Digital Quantum Simulation of spin transport  https://doi.org/10.1103/mx9k-kdlj

The data are already bootstrapped from the raw count results of the Qiskit sampler.
“Even” and “odd” refer to even-pair and odd-pair measurements, respectively, and “depo” denotes the experiment used to learn the renormalization factor.
